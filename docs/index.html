AI额度管家
跑在你自己电脑上的 AI 花费账本

DeepSeek、Kimi、智谱、MiniMax、硅基流动、火山方舟、百炼、OpenAI、Claude……散在各平台的余额和花销，一屏看完。回答三个问题：还有多少钱、这个月花了多少、什么时候快用完。

⬇ 下载 Windows 版 查看源码

它能帮你做什么

一个"判断账本"，不是行情终端。核心是把散落的额度变成一本能看懂的账。

💰

余额一屏总览

按量、订阅、在线订阅三类分列，各账号当前余额、本月消耗、累计消耗同口径汇总。

📈

趋势与账目统计

余额快照自动累积，自然月/自然年账目、按量真实消耗（余额下降额）、订阅按天摊销。

🔔

预算与微信预警

余额不足、消耗异常、每日日报，推送到企业微信或 Server酱。阈值自己定。

🔐

Key 永不出你的电脑

没有云端账号、不上传任何数据。密钥存本机，可开 DPAPI 加密；更新包带 Ed25519 防篡改签名。

🌍

多币种原币记账

CNY/USD/EUR/JPY/HKD/GBP，存储永远原币，换算只在展示层，汇率口径一目了然。

🖥️

桌面级体验

可选托盘壳：关窗收托盘、后台持续采集；也支持纯浏览器模式与 Linux/macOS 启动脚本。

平台支持（说实话版）

平台能力分三种，装之前先看清楚，不画饼。

平台余额获取方式说明
DeepSeek / Kimi / 硅基流动 / OpenRouter / Mistral全自动官方余额接口，定时查询
阿里百炼(AK/SK) / 火山方舟(Agent Plan·按量)全自动费用中心接口，按量需授予费用中心只读权限
MiniMax / 智谱 套餐档全自动账号级配额查询
OpenAI / Claude / Gemini / Grok / ChatAnywhere探活 + 手填官方不提供余额接口，任何软件都查不到；admin Key 可自动读成本报表
ChatGPT Plus / Claude Pro 等包月填月费按 月费÷当月天数 计入每日成本
⚠️ 海外平台（OpenAI/Claude/Gemini）能否连通取决于你本地的网络环境，软件本身不提供也不代理任何网络服务；有中转地址可在添加账号时填入「API 地址」。

三步跑起来

下载安装版（或绿色版解压到任意目录，建议 D:\AI额度管家，别放 C 盘 Program Files）
双击启动，浏览器自动打开 http://127.0.0.1:8788，全程本机、无需注册
「模型API管理 → 添加API账号」填入平台 Key，回到「当前总览」看账

Windows 10/11 可直接运行；Linux/macOS 从源码运行（Python 3.10+，后端零第三方依赖）。首次弹出「Windows 已保护你的电脑」→ 点「更多信息」→「仍要运行」（安装包未购买代码签名证书，属正常提示）。
